# NeteaseMusic

Netease Cloud Music controls and lyric display for FlexStudio.

## Features

- Custom Vue-rendered Now Playing view with album art and progress.
- Custom Vue-rendered synchronized lyrics with current-word highlight.
- Play / Pause, Previous, Next, and Play Mode controls.
- Config page with Netease Cloud Music, BetterNCM, and FlexLink setup steps.
- Uses NeteaseMusicLinkEssentials for the reusable FlexLink communication layer.

## Requirements

- Windows.
- Netease Cloud Music desktop client.
- BetterNCM.
- NeteaseMusicLinkEssentials installed and enabled in FlexStudio.
- The bundled FlexLink plugin installed into `C:\betterncm\plugins`.
